INNER JOIN
1. Write a query to display employee name and department name.
select employs.id,employs.name,departments.name from employs inner join departments on employs.id = departments.id;
2. Write a query to list employees working on projects.
select employs.id,employs.name,projects.name from employs inner join projects on employs.id=projects.id;
3. Write a query to find employees who are assigned to a department.
select * from employs inner join departments on employs.id=departments.id where departments.name != "null";
4. Display employee name and project name using INNER JOIN.
 select employs.id,employs.name,projects.name from employs inner join projects on employs.id=projects.id;


LEFT JOIN

RIGHT JOIN 
8. Write a query to display all departments, even if no employees work in them.
select employs.id,employs.name,departments.name from employs right join departments on employs.id=departments.id;


9. Display all projects, including those not assigned to any employee.
 select employs.id,employs.name,projects.name from employs right join projects on employs.id=projects.id;
